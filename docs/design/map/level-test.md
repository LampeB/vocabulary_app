## Décidé (utilisateur, 2026-08-06/07)
- Pour démarrer un niveau au-delà du courant, il faut RÉUSSIR un test
  prouvant la maîtrise des niveaux précédents
- Examen de maîtrise en fin de palier (ferme le niveau après les groupes)

## Proposé — pas encore vetté (Claude)
- Session mixte notée : vocab (deux sens) + grammaire
  (Reconnaître/Construire), ~20-30 items, pas de feedback par item
- Seuil ~85 % ; échec → bilan calme par domaine + étapes Renforcer,
  repassable à volonté
- Sert aussi de placement (onboarding « J'ai des bases », niveaux
  verrouillés « Je connais déjà ? »)
- Identité visuelle neutre (ni clay ni teal) — sobre, pas effrayant
- Débloqué quand tous les groupes du niveau sont ✓
