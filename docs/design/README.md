# Design V3

La référence de design et d'implémentation est
[V3 — Sentier de cartes](v3-sentier-de-cartes.md). Elle décrit ce qui est
livré, ce qui manque et les règles visuelles à préserver.

Les décisions par zone (parcours, leçons, vocabulaire, quiz, langues,
navigation) sont dans [map/](map/app-map.md). Toute décision de design doit
mettre à jour la note concernée, puis la référence V3 lorsqu'elle affecte la
vertical slice.

Le seul prototype HTML conservé est
[l'aperçu du plateau V3](mockups/v3-home-plateau-preview.html). Les surfaces,
ondulations et animations de production restent dessinées dans Flutter ; ne pas
introduire d'asset raster pour les simuler.
