# Prototype V3

[`v3-home-plateau-preview.html`](v3-home-plateau-preview.html) est le seul
prototype interactif conservé. Il sert à discuter le plateau, le rythme des
ondulations et la hiérarchie de la page d'accueil V3.

Il n'est pas du code de production : la référence fonctionnelle est
[`../v3-sentier-de-cartes.md`](../v3-sentier-de-cartes.md), et le rendu réel
est dans Flutter.
