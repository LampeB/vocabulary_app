Le flux complet d'une leçon du parcours

Une règle du parcours, de la découverte à la production libre, vue côté apprenant. Exemple réel du catalogue : « Le présent de l'indicatif (-ar / -er / -ir) » (es-present-indicative), apprenant francophone, espagnol · Niveau 1. Type de leçon : conjugaison — l'UI dit « leçon », jamais « grammaire ». Chaque phrase affichée n'utilise que du vocabulaire déjà connu de l'apprenant.

S9

Le point de départ — fiche de cluster, onglet Leçons

Le chemin d'un niveau est une suite de clusters de ~5 leçons liées, débloqués un par un. Dans le cluster ouvert, l'ordre est libre — chaque leçon garde sa porte de vocabulaire (≥ 80 % de mots connus, toutes listes confondues). Valider le Mélange ferme le cluster et ouvre le suivant. Une seule grammaire d'états partout : ✓ fait · 📖 en cours · ▶ prête · 🔒 verrouillée.

La leçon — visionneuse S4, « moins un quiz, plus une leçon »

Paginée, une idée par écran, 3-6 pages, jamais un mur de texte. Les pages alternent explication → exemple(s) → explication. Navigation libre dans les deux sens, aucune note, reprise où on s'est arrêté. Chaque page se lit à voix haute — voix distinctes par rôle : narrateur en français, exemples en espagnol.

Construire — la rampe de distracteurs — chips → production tapée

Le cœur de la décision anti-Duolingo : au début on applique et on analyse avec les chips exacts ; à chaque palier réussi, des distracteurs s'ajoutent — pour qu'on ne puisse plus résoudre par la position des mots, il faut appliquer la règle. Au bout de la rampe, plus de chips : on tape la phrase soi-même. Construire → Écrire est un continuum, pas deux exercices.

Le Mélange — le quiz de validation du cluster

Une vraie phrase n'utilise jamais une règle isolée. Quand les leçons du cluster sont faites, le Mélange enseigne leur interaction — même visionneuse S4, mais le sujet est la combinaison — puis une session mixte le prouve. Réussi → cluster ✓, le suivant s'ouvre.

Et après — la règle vit dans les révisions

Une règle « finie » n'est pas rangée : elle revient en cloze et dialogues dans les révisions du chemin quotidien, mêlée au vocabulaire FSRS. Cluster après cluster, le niveau se remplit ; le test de palier (S17) ferme le niveau — le réussir déverrouille toutes les règles du niveau suivant.
