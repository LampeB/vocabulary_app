# Registre des décisions

Les décisions structurantes et durables sont consignées ici sous forme d'ADR
(Architecture / Product Decision Record). Elles complètent les spécifications :
une ADR explique le contexte, la décision et ses conséquences ; la
spécification décrit le comportement à implémenter.

## Règles

- Créer une ADR lorsqu'un choix modifie le produit, l'architecture, les règles
  pédagogiques, la confidentialité, une dépendance externe ou le mode de test.
- Nommer le fichier `YYYY-MM-DD-sujet-kebab-case.md`.
- Lier l'ADR depuis le document canonique concerné et depuis
  [`../knowledge-base/00-Accueil.md`](../knowledge-base/00-Accueil.md) si elle
  change l'orientation générale.
- Ne pas réécrire une décision acceptée : la remplacer par une nouvelle ADR qui
  indique explicitement ce qui est remplacé.

## Modèle

Copier [TEMPLATE.md](TEMPLATE.md) pour toute nouvelle décision.
