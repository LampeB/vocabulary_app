# Runbooks

Des procédures opérationnelles courtes, vérifiables et maintenues avec le code.
Elles ne contiennent jamais de secrets.

| Procédure | Usage |
| --- | --- |
| [Documentation et commits](documentation-et-commits.md) | Installer le garde-fou documentaire et préparer un commit |
| [Démarrage local](../../README.md#Getting-started) | Installer les dépendances, configurer `.env.json`, lancer l'app |
| [Compte E2E](e2e-account.md) | Activer le reset par scénario et les E2E du soir |
| [Tests](../../TESTS.md) | Choisir et lancer la suite pertinente |

Lorsqu'une procédure échoue ou devient ambiguë, corriger ce runbook dans le
même lot que le changement qui la rend nécessaire.
